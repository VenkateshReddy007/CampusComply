# Local synthetic demo fixtures

Run `python scripts/create_synthetic_demo_pdfs.py` from the repository root to
create two local PDFs in this folder. Their claims are invented and marked in
the PDF text as **synthetic software test fixtures only**. The generated PDFs
are ignored by Git. Use them only to exercise upload, retrieval, citation, and
conflict UI behavior; never treat them as real campus regulations or include
them in policy-quality evaluation.
